# JARVIS: تدقيق شامل

## 1. الهيكل
تطبيق Kotlin (`com.jarvis.tablet`): `Engine` (العقل وتنفيذ الأوامر، 60 أمر)، `JarvisAccessibility` (التحكم)، `Brain` (ذاكرة مشفّرة + embeddings + مهارات)، `Router` و`Usage` و`Health` (اختيار الموديلات)، `PromptDiet`، `Vault/Keys` (تشفير)، `AutoReply/CallReceiver` (المذاكرة)، `GitHub/Problems` (التقارير). الواجهة: WebView (`jarvis-hud.html`). وخارج التطبيق: Workflows للبناء، والمهندس الذاتي، وصائد المهارات.

## 2. إيه اللي اتفحص وإزاي
| الفحص | النتيجة |
|---|---|
| بناء Gradle + اختبارات Kotlin (`testDebugUnitTest`) على كل push | ناجح؛ الاختبارات بتشتغل فعلاً |
| اختبارات Python (محرك الاكتشاف، قواعد الدمج): 22 اختبار | ناجحة |
| `actionlint` على كل الـ workflows | بدون ملاحظات |
| كل أمر في الـ prompt له معالج في الكود (60/60) | سليم |
| كل دالة `AndroidBridge` بتنادي عليها الـ HUD موجودة | سليم |
| صياغة JS في الـ HUD (`node --check`)، IDs مكررة أو ناقصة | سليم |
| منطق branch البيانات (إنشاء/متابعة/عدم لمس main) | جُرّب على ريبو محلي |
| بحث GitHub الحقيقي (dry-run) | اشتغل، فلاتر الأمان رفضت المتوقع |
| بوت الإصلاح على Issue حقيقي | الأساسيات اشتغلت؛ **التشخيص بالنموذج لسه مجرّبش** (مفيش مفتاح في Secrets) |
| **التجربة على موبايل حقيقي** | **جزئية: لوحة ENGINEER اشتغلت على موبايلك. باقي الميزات ما اتجرّبتش** |

## 3. عيوب لقيتها وصلّحتها (من تقارير موبايلك الحقيقية)
1. **`healthCheck` بتضرب كل المزودين مرة واحدة وتلقائياً** (عند التشغيل وكل 6 ساعات)، وأي فشل بيعطّل المزود 24 ساعة. ← بقت عند الطلب فقط، واحد ورا التاني، بتتحقق من المفتاح بـ `GET /models` (من غير استهلاك حصة توليد)، ومش بتعطّل حاجة.
2. **الـ prompt متضخم:** حوالي 13.7 ألف حرف + قائمة 200 تطبيق + أسماء الجهات في كل طلب. ده سبّب `413` من Groq ثم "الرصيد خلص". ← `PromptDiet` بيضيف كل جزء بس لما الطلب يحتاجه، والـ Router بيتجنب Groq للطلبات الكبيرة، و`413` ما بقتش تعطّل المزود.
3. **Gemini 2.5 Flash بيفكّر افتراضياً:** بطيء على 4G، وبيتحاسب كـ tokens. ← `thinkingBudget=0` (**لسه ما اتجرّبش على موبايل**).
4. **رسالة "فعّل الـ Accessibility" وهي متفعلة:** تقريرك أثبت `lastConnected=0`، يعني أندرويد ما شغّلهاش منذ بدء التطبيق (شاومي). ← الرسالة بقت دقيقة وفيها خطوات شاومي (Autostart، No restrictions، تثبيت في Recents).
5. اختيار الموديلات: `llmCall` و`agentChat` كانوا متتابعين أصلاً. ← أضفت Router بتصنيف مهام، وحد 3 محاولات، وCooldown ذكي، وإحصائيات، وتحكم صوتي، وتفضيل لكل نوع مهمة.

## 4. مشاكل في إعداداتك (مش أخطاء كود)
- OpenAI وDeepSeek وKimi: **رصيد منتهي** (402/quota). محتاجين شحن، أو سيبهم من غير مفتاح.
- Groq المجاني: حد الطلب صغير. الـ Router بيتجنبه للطلبات الكبيرة.
- المحرك المحلي مفعّل لكن `llama-server` مش شغال، فبيفشل في كل طلب ويسجّل مشاكل. عطّله من الإعدادات لو مش بتستخدمه.
- Gemini بيرجّع 503 (ضغط عليه) وTimeouts أحياناً.

## 5. مواصفاتك مقابل الواقع
| البند | الحالة |
|---|---|
| تدقيق + فرع منفصل + عدم حذف حاجة | تم (كل الشغل على `upgrade/agent-wake`، و`main` ما اتلمسش) |
| **Router** | **منفذ** (فوق). لم أقيّم LiteLLM/OmniRoute بعد؛ القرار المؤقت راوتر مدمج بدون خدمة وسيطة |
| ذاكرة | موجودة (مشفّرة، بحث، تلخيص، استرجاع من GitHub). **ناقص:** انتهاء صلاحية الذكريات، تعديل/حذف من الواجهة، فصل خاص/مشاريع كامل |
| تخطيط وAgent مستقل | Agent متعدد الخطوات (30)، بكشف التعليق. **ناقص:** حالة مهام دائمة، تنفيذ في الخلفية، إلغاء، نقاط موافقة |
| اكتشاف المهارات | **منفذ** (`docs/SKILL_HUNTER.md`). ما اتجرّبش بنموذج |
| تحكم أندرويد | شامل في الشاشة والتطبيقات والمكالمات والكاميرا. **ناقص:** إدارة الملفات والمستندات (مفيش صلاحيات تخزين) |
| **Windows Companion** | **غير منفذ** |
| بحث الويب وأتمتة المتصفح | **غير منفذ** (فتح روابط وبحث يوتيوب فقط) |
| صوت (Whisper.cpp/Sherpa/Piper) | **غير منفذ**؛ الموجود سحابي + تعرف على الجهاز |
| وكلاء متخصصة | **غير منفذ**؛ وكيل واحد + المهندس الذاتي |
| مستندات وRAG وOCR | **غير منفذ** |
| تقويم وتذكيرات | موجود؛ إيميل ومهام **غير منفذ** |
| MCP وسجل أدوات | **غير منفذ** (قائمة الأوامر هي السجل الفعلي بدون صلاحيات/إحصائيات) |
| أمان | تشفير Keystore، قفل ببصمة، إخفاء المفاتيح من التقارير، تأكيد صوتي. **ناقص:** سجل مراجعة، فحص تبعيات |
| أتمتة بأحداث وجداول | ماكرو بسيط موجود؛ الباقي **غير منفذ** |

## 6. ترتيب مقترح للباقي
1. جرّب النسخة دي على موبايلك وابعتلي النتايج (أهم خطوة).
2. مفتاح نموذج في Secrets عشان المهندس والصائد يشتغلوا فعلاً.
3. بحث ويب حقيقي (مصادر متعددة + تلخيص) كأداة في الـ Agent.
4. مهام خلفية دائمة مع إلغاء ونقاط موافقة (WorkManager).
5. Windows Companion (عبر Tailscale + وكيل صغير بقائمة أوامر مسموحة وموافقة).
6. الصوت المحلي (Sherpa-ONNX) للعربي المصري.
