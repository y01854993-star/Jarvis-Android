# JARVIS (جرجس): دليل المشروع

مساعد صوتي لأندرويد بيتحكم في الموبايل عن طريق خدمة Accessibility. الكود كله في الريبو ده، والحزمة `com.jarvis.tablet`.

## فين كل حاجة
| الحاجة | المكان |
|---|---|
| الكود | `app/src/main/java/com/jarvis/tablet/` |
| الواجهة (HUD) | `app/src/main/assets/jarvis-hud.html` + `hud_bridge.js` |
| الإعدادات الأولية | `app/src/main/assets/config.json` |
| بناء الـ APK | `.github/workflows/build.yml` |
| بوت إصلاح المشاكل | `.github/workflows/autofix.yml` + `.github/autofix/autofix.py` |
| دليل المشروع | `docs/PROJECT.md` (الملف ده) |
| المهندس الذاتي (تشخيص + إصلاح + موافقة) | `docs/AUTONOMOUS_ENGINEER.md` |

## إزاي توصل للـ APK
- **أي branch غير main:** تبويب *Actions* ← آخر Run ← **Artifacts** ← `jarvis-apk-build-N` (zip فيه الـ APK).
- **main:** تبويب *Releases* ← `latest`. (بيتحدّث تلقائياً مع كل دمج في main.)
- **لوج البناء:** *Releases* ← `buildlog` ← `buildlog.txt`.
- التوقيع ثابت (`debug.keystore` في الريبو)، فالنسخة الجديدة بتتثبّت فوق القديمة من غير ما تفقد بياناتك.

## أول تشغيل
1. Secret باسم `GEMINI_API_KEY` في إعدادات الريبو (Settings ← Secrets and variables ← Actions).
2. ثبّت الـ APK، وامنحه: Accessibility، قراءة الإشعارات، الظهور فوق التطبيقات، الميكروفون، الكاميرا.
3. من ⚙ ادخل اسمك ومفتاح Gemini، واضغط *SAVE & CONNECT*.
4. (اختياري) GitHub Token + Repo للذاكرة والتقارير. استخدم توكن Fine-grained بأقل صلاحيات.

## القدرات
- **Agent متعدد الخطوات (حتى 30 خطوة):** بيقرأ الشاشة (عناصر + لقطة)، وبيكشف التعليق والتكرار، وبيجرب طريقة تانية.
- **أفعال:** ضغط، ضغط طويل، كتابة، سحب، ضغطتين وسحب بإحداثيات، لصق، Enter، لقطة شاشة، قفل، قائمة الطاقة، فتح تطبيق، `deep_link` (تليجرام/زوم/انستجرام/واتساب).
- **الرؤية:** `look` للشاشة و`camera_look` للكاميرا (محتاج إنترنت ومفتاح سحابي).
- **وضع المذاكرة:** "هذاكر نص ساعة" ← بيرد على المكالمات وواتساب (الشات الخاص)، وبيبلغك بملخص لما يخلص.
- **الذاكرة:** مشفّرة محلياً، وبتتزامن على GitHub (`brain/memory.json`) وبترجع تلقائياً بعد تسطيب جديد لو فاضية.
- **الموديلات:** بتتجرب واحد ورا التاني. لو خلص رصيد المزود بيتقفل يوم، ولو حد استخدام مؤقت 3 دقايق.
- **Wake Word:** محلي على أندرويد 13+ لو التعرف الأوفلاين متاح، وإلا بيرجع للطريقة القديمة.
- **تدريب ذاتي:** قول "درّب نفسك" ← 5 مهام آمنة، واللي ينجح بيتحفظ كمهارة.
- **بوت المشاكل:** التطبيق بيبعت المشاكل كـ Issue (label `jarvis-problem`) ← الـ workflow بيقترح إصلاح ويفتح Pull Request بعد ما يتأكد إنه بيتبني. مفيش دمج تلقائي.

## اللغة والاسم
- زرار AR/EN فوق بيغيّر **كل حاجة**: نصوص الواجهة، ولغة التعرف على الكلام، ولغة ردود جارفيس، واسمه (جارفيس / Jarvis). الاختيار بيتحفظ.

## ريبو التقارير
- الذاكرة بتتزامن على الريبو اللي في إعدادات GitHub (مثلاً `jarvis-brain`).
- تقارير المشاكل بتروح لريبو منفصل: `y01854993-star/Jarvis-Android` (قابل للتغيير بالمفتاح `fixrepo`). التوكن اللازم لازم يكون له صلاحية Issues على الريبو ده.

## الأمان
- المفاتيح مشفّرة بـ Android Keystore، والميزات الحساسة تقدر تتقفل ببصمة/قفل الجهاز.
- الأفعال الخطيرة (إرسال، دفع، مسح) بتطلب تأكيد صوتي.
- لا تحفظ توكن GitHub في أي ملف في الريبو.

## حدود معروفة
- الـ Wake Word بنموذج مدرّب لـ "يا جرجس" لسه مش موجود (محتاج تدريب على GPU).
- الرد على الرسائل الصوتية في واتساب مش ممكن (الإشعار نص بس).
- تحميل الموسيقى بيتم من تطبيق الموسيقى بتاعك (زر Download، باشتراكك) مش من مواقع خارجية.
- بوت المشاكل بيشتغل بعد دمج `autofix.yml` في main.
- التعديلات الأخيرة اتبنت بنجاح لكنها محتاجة تجربة على موبايل حقيقي.
